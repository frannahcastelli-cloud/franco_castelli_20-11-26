# franco_castelli_20-11-26
Proyecto de semáforo con Arduino realizado en Wokwi.

El proyecto de un semáforo en Wokwi consiste en crear un semáforo usando Arduino y tres luces LED: roja, amarilla y verde.
Los LED se conectan a diferentes pines del Arduino y se programan para que se prendan y apaguen en orden. Primero se prende la luz roja para indicar que hay que detenerse, después la amarilla como señal de precaución y por último la verde para poder avanzar. Cada luz permanece encendida unos segundos y después cambia automáticamente.
Con este proyecto podemos aprender cómo conectar componentes y cómo programar Arduino para que controle las luces. Todo se realiza de forma virtual en Wokwi, sin necesitar los materiales físicos.
